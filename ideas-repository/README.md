# Research-derived software opportunities

## Primary thesis

The strongest opportunities sit at the control layer around autonomous software: authorization, provenance, evidence, durability, and integration reliability. The inputs show that agent capability is expanding faster than the surrounding governance and operational infrastructure.

## Recommended sequencing

1. Start with the least-privilege control plane because the buyer, risk, and measurable value are clearest.
2. Add the evidence ledger to make agent activity auditable and improve trust.
3. Expand into durable workspaces and integration contract monitoring after establishing a common event and policy model.
4. Pursue dependency integrity and vulnerability coordination as a separate security product line or adjacent module.

## Validation principles

- Prefer deterministic checks over self-reported model confidence.
- Store evidence and decisions as first-class records.
- Make permissions time-bounded, task-scoped, and revocable.
- Test destructive workflows in isolated environments before production execution.
- Measure false positives, recovery time, approval latency, and prevented incidents.

## Main uncertainty

The inputs provide strong engagement signals but limited direct evidence of willingness to pay, deployment constraints, procurement cycles, or integration depth. Customer interviews and workflow-level pilots are required before committing to a broad platform strategy.
