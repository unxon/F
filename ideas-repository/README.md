# Research-derived software opportunity repository

## Scope
This repository converts the supplied technical and product signals into software opportunities. Evidence is limited to the supplied inputs. Engagement counts indicate attention or interest, not validated purchasing demand.

## Selection criteria
- Clear operational or compliance pain
- Technical depth beyond generic content generation
- Feasible initial implementation
- Evidence of demand, urgency, or emerging workflow change
- Potential for recurring or outcome-linked revenue

## Priority themes
1. Reliability and governance for agentic software workflows
2. Security boundaries for local and model-driven execution
3. Cost attribution for bursty computational workloads
4. Monitoring for distributed energy assets
5. Accessibility remediation and regression control
6. Compatibility assurance for legacy desktop software

## Validation principle
The next research phase should test buyer identity, current workaround cost, data access, deployment constraints, measurable success criteria, and willingness to pay. Signals labeled as inference require direct customer validation before significant investment.
