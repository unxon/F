# Opportunity portfolio

## Strategic thesis
The strongest opportunities are control-plane products for autonomous software: systems that verify outcomes, constrain actions, isolate execution, and preserve evidence. These products address operational risk that becomes more expensive as agent adoption grows.

## Prioritization logic
1. Prefer infrastructure with recurring usage and high switching costs.
2. Start with measurable failure, security, or compliance outcomes.
3. Make auditability and replay first-class features.
4. Avoid dependence on a single model or user interface.
5. Begin with one narrow workflow before expanding horizontally.

## Recommended sequencing
- Phase 1: Build the failure observatory and secure action gateway as independent instrumentation and policy layers.
- Phase 2: Add isolated execution and durable workspace coordination.
- Phase 3: Apply the same evidence and control primitives to generated-code assurance and operational forecasting.

## Validation metrics
- Reduction in undetected task failures.
- Percentage of automated actions covered by policy.
- Mean time to reproduce and resolve incidents.
- Review time saved per generated change.
- Forecast calibration and operational response improvement.

## Key assumptions
These opportunities are based on signals and inferences from the supplied research inputs. Demand strength should be validated through customer interviews, workflow observation, and paid pilot commitments.
